# Suporte — Restock

Rascunhos de resposta a tickets e reviews (regra 14 do CLAUDE.md).
O Claude Code escreve o rascunho aqui; o humano só envia quando a plataforma exigir login.

## Convenção de arquivo

`AAAA-MM-DD-canal-assunto.md` — ex.: `2026-09-14-review-etiqueta-cortada.md`

Cada arquivo contém:
- **Contexto:** o que o usuário relatou, loja, plano
- **Diagnóstico:** causa provável / se virou bug no backlog
- **Rascunho:** texto pronto para enviar, no idioma do usuário
- **Status:** `rascunho` → `enviado` (com data)
